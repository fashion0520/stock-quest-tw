# 經驗紀錄

這份文件只記錄已在專案中實際觀察或驗證的做法，並標明可重用範圍。不要把原型簡化假設當成正式交易規格。

## E-001｜GitHub Pages 可承載無建置步驟的靜態原型

- **經驗**：單頁 HTML/CSS/JavaScript 可以由 Actions 直接打包根目錄並發布，無須先引入框架或建置流程。
- **未來適用範圍**：本專案的靜態介面、文件頁與小型學習工具。
- **界線**：需要機密 API key、登入、跨裝置同步或伺服器驗證時，不能把秘密放在靜態前端，應另設可信任後端。

## E-002｜示意行情要在每個關鍵位置清楚標示

- **經驗**：儀表板外觀像真實行情時，單靠頁尾聲明容易令人誤認。示意狀態要出現在行情總覽、個股／下單區與說明文字。
- **未來適用範圍**：所有股票報價、指數、圖表、報酬率與模擬成交價；未來可延伸成來源及更新時間欄位。
- **界線**：視覺標示不取代資料供應商授權。
